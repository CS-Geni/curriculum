# CS-Geni curriculum

The readable study map for [CS-Geni](https://cs-geni.github.io/public/): **12 tracks**, **15 courses**, **145 lessons**, about **482 hours**.

The website is where you take a lesson, answer a check, and keep progress. This repository is the same public catalog, written so you can read the path in order, print a course, or review a capstone before you start it. Book text stays on the authors' sites.

## Start here

1. Open the [learning site](https://cs-geni.github.io/public/).
2. Read [Computer Science Without the Jargon](courses/computer-thinking.md) if you are new to the field.
3. Build the five exercises in [cs-geni/labs](https://github.com/CS-Geni/labs) while you are in the first programming course.
4. Use the matching brief in [cs-geni/projects](https://github.com/CS-Geni/projects) when you reach a capstone.

## Tracks

### Start from zero

*CS0 · Onboarding.* Build confidence with computers, code, and the command line—no prior experience assumed.

- [Computer Science Without the Jargon](courses/computer-thinking.md) — Learn what computers actually do, how programmers turn messy ideas into precise steps, and how to feel at home in a technical world.
- [Python: Your First Programs](courses/python-first-steps.md) — Write useful programs from day one while learning variables, decisions, loops, functions, and the habit of testing your ideas.

### Programming foundations

*Core skill.* Learn to design programs, break down problems, and write code you can trust.

- [Python: Your First Programs](courses/python-first-steps.md) — Write useful programs from day one while learning variables, decisions, loops, functions, and the habit of testing your ideas.
- [Designing Reliable Programs](courses/program-design.md) — Move beyond syntax: turn requirements into small components, manage complexity, test behavior, and communicate your design.

### Data structures & algorithms

*CS core.* Choose the right structure, reason about efficiency, and solve problems systematically.

- [Data Structures in Practice](courses/data-structures.md) — Build the structures behind fast software and learn when arrays, lists, stacks, queues, trees, maps, and graphs fit.
- [Algorithmic Problem Solving](courses/algorithmic-thinking.md) — Learn reusable strategies—divide and conquer, greedy choice, dynamic programming, and graph algorithms—without puzzle-game tricks.

### Math for computer science

*CS core.* Build proof, logic, graph, counting, and probability skills through visual problems.

- [Discrete Math for Builders](courses/discrete-math.md) — Learn the logic, proofs, counting, graphs, and probability that make computer science click—through code and concrete examples.

### Systems & architecture

*Under the hood.* Connect bits, memory, processors, compilers, and the programs they run.

- [Inside a Computer](courses/inside-computers.md) — Travel from binary and logic gates through processors, memory, C programs, and the toolchain that turns code into action.

### Operating systems

*CS core.* Understand processes, concurrency, memory, persistence, and the Unix model.

- [How Operating Systems Work](courses/operating-systems.md) — Understand how an OS shares processors, isolates memory, coordinates concurrent work, and stores data reliably.

### Networks & distributed systems

*Connected world.* Follow a request across the internet and design reliable networked software.

- [Networks from First Principles](courses/computer-networks.md) — Follow data from your app to the wire and back while learning layers, protocols, routing, HTTP, and reliable communication.

### Databases

*Data foundations.* Model information, query it with SQL, and make data systems dependable.

- [Databases That Make Sense](courses/database-design.md) — Turn real-world information into clear data models, query with SQL, and understand indexes, transactions, and tradeoffs.

### Software engineering & DevOps

*Professional practice.* Collaborate with Git, test effectively, ship safely, and operate real software.

- [Git & Collaborative Development](courses/git-collaboration.md) — Build a safe mental model of version control, work confidently with branches, and collaborate through clear reviews.
- [Shipping & Operating Software](courses/shipping-software.md) — Connect testing, continuous integration, deployment, observability, and reliability into a humane delivery practice.

### Security

*Defensive practice.* Develop a security mindset and learn to build safer systems from the start.

- [Secure by Design](courses/secure-by-design.md) — Learn defensive thinking, threat modeling, identity, cryptography basics, web risks, and secure development without exploit-first teaching.

### AI & data

*Intelligent systems.* Move from data literacy to models, evaluation, and responsible machine learning.

- [Data & AI Foundations](courses/data-ai-foundations.md) — Explore the full machine-learning workflow: frame a question, prepare data, train a model, evaluate honestly, and consider impact.

### Advanced electives

*Choose your depth.* Build an interpreter, explore distributed systems, or study graphics and theory.

- [Build Your Own Language](courses/crafting-language.md) — Bring together algorithms, systems, and software design by creating a programming language from scanner to virtual machine.
