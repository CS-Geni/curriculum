# Data Structures in Practice

**Data structures & algorithms** · Intermediate · 34 hours · 12 lessons

Build the structures behind fast software and learn when arrays, lists, stacks, queues, trees, maps, and graphs fit.

Open the [CS-Geni learning site](https://cs-geni.github.io/public/) and choose **Data Structures in Practice**. Progress on that site stays in your browser.

## You will be able to

- Implement core data structures
- Compare time and space tradeoffs
- Select structures for real requirements
- Explain recursion with call diagrams

## Before you start

- Designing Reliable Programs
- Comfort with functions and classes

## Modules

### Measure the work

Develop intuition for growth and efficiency.

1. Why performance changes
2. Big O as a vocabulary
3. Measure real code

### Linear structures

Build arrays, linked lists, stacks, and queues.

1. Arrays and dynamic arrays
2. Linked structures
3. Stacks and queues

### Fast lookup

Explore hashing, trees, and priority queues.

1. Hash tables
2. Binary search trees
3. Heaps

### Connected data

Represent and traverse graphs.

1. Graph models
2. Breadth-first search
3. Depth-first search

## Capstone: Route finder

Model a transit network as a graph and find useful routes while explaining the tradeoffs.

The brief, and the checklist for calling it done, is in [projects](https://github.com/CS-Geni/projects/blob/main/briefs/data-structures.md).

- Stops and connections are a graph, not a pile of special cases.
- The program finds one useful route between two stops.
- You can say what gets slower as the network grows, and why you chose that structure.
