# Python: Your First Programs

**Programming foundations** · Beginner · 24 hours · 16 lessons

Write useful programs from day one while learning variables, decisions, loops, functions, and the habit of testing your ideas.

Open the [CS-Geni learning site](https://cs-geni.github.io/public/) and choose **Python: Your First Programs**. Progress on that site stays in your browser.

This course also sits on **Start from zero**.

## You will be able to

- Write and run small Python programs
- Model data with core Python types
- Use decisions, loops, and functions
- Debug common errors methodically

## Before you start

- Computer Science Without the Jargon, or equivalent computer comfort

## Modules

### Make the computer respond

Start with expressions, values, variables, and input.

1. Hello, Python
2. Values have types
3. Remember with variables
4. Ask the user

### Make decisions

Control what happens and repeat useful work.

1. True, false, and comparisons
2. Choose with if
3. Repeat with loops
4. Trace your program

### Design with functions

Turn solutions into small, reusable parts.

1. Why functions matter
2. Inputs and outputs
3. Scope without surprises
4. Test a function

### Work with collections

Store and transform groups of related values.

1. Lists
2. Strings as sequences
3. Dictionaries
4. Read and write files

## Capstone: Personal study planner

Build a command-line planner that stores tasks, estimates study time, and reports what to do next.

The brief, and the checklist for calling it done, is in [projects](https://github.com/CS-Geni/projects/blob/main/briefs/python-first-steps.md).

- You can add a task with a title and a time estimate in minutes.
- You can mark a task done.
- The program reports the next unfinished task and the minutes still left.
- An empty title or a negative time is rejected with a message you can understand.
