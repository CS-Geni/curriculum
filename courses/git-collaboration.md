# Git & Collaborative Development

**Software engineering & DevOps** · Beginner · 12 hours · 9 lessons

Build a safe mental model of version control, work confidently with branches, and collaborate through clear reviews.

Open the [CS-Geni learning site](https://cs-geni.github.io/public/) and choose **Git & Collaborative Development**. Progress on that site stays in your browser.

## You will be able to

- Explain commits, branches, and remotes
- Recover from common mistakes
- Create focused pull requests
- Give useful code review feedback

## Capstone: Open-source contribution simulation

Take a small issue from branch to pull request, review, conflict resolution, and merge.

The brief, and the checklist for calling it done, is in [projects](https://github.com/CS-Geni/projects/blob/main/briefs/git-collaboration.md).

- The change lives on a branch.
- The pull request says what changed and how you checked it.
- A review comment is answered in the code, not only in chat.
- A merge conflict is resolved by keeping both intentions, and the history is readable.
