# Algorithmic Problem Solving

**Data structures & algorithms** · Intermediate · 42 hours · 9 lessons

Learn reusable strategies—divide and conquer, greedy choice, dynamic programming, and graph algorithms—without puzzle-game tricks.

Open the [CS-Geni learning site](https://cs-geni.github.io/public/) and choose **Algorithmic Problem Solving**. Progress on that site stays in your browser.

## You will be able to

- Prove why an algorithm works
- Analyze running time
- Apply common design strategies
- Recognize when tradeoffs beat a single best answer

## Before you start

- Data Structures in Practice
- Discrete Math for Builders

## Modules

### Reason about algorithms

Correctness and efficiency in plain language.

1. State the promise
2. Loop invariants
3. Worst and average cases

### Design strategies

Build a toolbox of reusable approaches.

1. Divide and conquer
2. Greedy algorithms
3. Dynamic programming

### Graph problems

Solve routing, dependency, and connection problems.

1. Shortest paths
2. Minimum spanning trees
3. Topological order

## Capstone: Community delivery optimizer

Compare algorithms that schedule deliveries under time and capacity constraints.

The brief, and the checklist for calling it done, is in [projects](https://github.com/CS-Geni/projects/blob/main/briefs/algorithmic-thinking.md).

- The same set of deliveries is scheduled by two different methods.
- You record time and capacity limits before you compare the methods.
- The write-up says which method you would ship, and one case where it is worse.
