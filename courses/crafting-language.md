# Build Your Own Language

**Advanced electives** · Advanced · 52 hours · 9 lessons

Bring together algorithms, systems, and software design by creating a programming language from scanner to virtual machine.

Open the [CS-Geni learning site](https://cs-geni.github.io/public/) and choose **Build Your Own Language**. Progress on that site stays in your browser.

## You will be able to

- Implement scanning and parsing
- Represent and evaluate syntax trees
- Design lexical scope and functions
- Build a bytecode virtual machine

## Before you start

- Data Structures in Practice
- Inside a Computer
- Designing Reliable Programs

## Modules

### Understand source

Tokens, grammar, syntax trees, and errors.

1. Scan characters
2. Parse expressions
3. Report useful errors

### Make it run

Evaluation, environments, and control flow.

1. Tree-walk evaluation
2. Variables and scope
3. Functions and closures

### Build a virtual machine

Bytecode, stacks, memory, and optimization.

1. Compile to bytecode
2. A stack machine
3. Garbage collection

## Capstone: A tiny useful language

Design, implement, test, and document a small language with functions, closures, and a REPL.

The brief, and the checklist for calling it done, is in [projects](https://github.com/CS-Geni/projects/blob/main/briefs/crafting-language.md).

- The language has numbers, names, and function calls.
- A function can close over a value from outside.
- Bad syntax produces an error that points at the problem.
- A short program runs in a prompt you can type into.
- The language is documented on one page a new reader can try.
