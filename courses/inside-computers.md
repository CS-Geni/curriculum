# Inside a Computer

**Systems & architecture** · Intermediate · 38 hours · 9 lessons

Travel from binary and logic gates through processors, memory, C programs, and the toolchain that turns code into action.

Open the [CS-Geni learning site](https://cs-geni.github.io/public/) and choose **Inside a Computer**. Progress on that site stays in your browser.

## You will be able to

- Explain binary representation
- Trace instructions through a processor
- Reason about memory and pointers
- Describe compilation and linking

- Python: Your First Programs

### Bits become behavior

Representation, logic, and digital building blocks.

1. Binary and hex

3. From gates to circuits

### A programmable machine

Processors, memory, and instructions.

1. The CPU cycle
2. Memory hierarchy
3. Assembly as a lens

### Systems programming

Use C to understand memory and tools.

1. C and the machine
2. Pointers and allocation
3. Compile and link

## Capstone: Tiny virtual machine

Implement a small stack-based computer and run a custom instruction set.

The brief, and the checklist for calling it done, is in [projects](https://github.com/CS-Geni/projects/blob/main/briefs/inside-computers.md).

- The machine has a stack and a tiny instruction set you document.
- A program of your instructions adds two numbers and stops.
- An unknown instruction stops the machine with an error instead of guessing.
